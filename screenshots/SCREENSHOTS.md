# Какие скриншоты сделать

Сохраняйте в эту папку (`screenshots/`) с точно такими именами — README уже ссылается на них.
На Mac: **Cmd + Shift + 4**, затем **пробел** и клик по окну — снимок одного окна.

| Файл | Что снять |
|---|---|
| `01-ankiconnect-install.png` | Anki → Инструменты → Дополнения → окно «Получить дополнения» с кодом 2055492159 (или список дополнений, где виден AnkiConnect) |
| `02-anki-note-fields.png` | Anki → Инструменты → Управление типами записей → YOMITAN_ASBPLAYER → Поля |
| `04-claude-add-folder.png` | Приложение Claude: меню «+» → Add folder (или уже подключённая папка ankiScripts над полем ввода) |
| `05-claude-project-instructions.png` | Страница проекта «Anki LangVoc» с открытыми инструкциями |
| `06-claude-chat-words.png` | Ваше сообщение со словами (текстом или скриншотом) |
| `07-claude-summary.png` | Ответ Claude: сводка по карточкам и команда |
| `08-terminal-output.png` | Терминал после `python3 eng_add_cards.py` |
| `09-anki-card.png` | Готовая карточка в Anki (обратная сторона: картинка, пример, транскрипция) |

Перед публикацией проверьте, что на скриншотах нет личных данных (почта, имена в чатах, другие вкладки).
Этот файл после этого можно удалить.
